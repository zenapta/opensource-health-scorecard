# OpenSource Health Scorecard 📊

**OpenSource Health Scorecard** is an automated intelligence tool that evaluates the health, reliability, and maintenance status of GitHub repositories, helping you stop wasting time on abandoned dependencies and build your stack on solid ground. The problem it solves is critical: integrating an abandoned library is a ticking time bomb for your production apps, and most developers only check "stars," which don't tell you if the project is actually maintained. This tool automatically parses GitHub repositories and rates them based on three key metrics—Maintenance Velocity (how fast do they respond to issues?), Commit Activity (is the project currently active or abandoned?), and Community Health (are there active contributors and a healthy release cycle?)—giving you a comprehensive 0-100 score. You don't need to install anything to try it out; simply run it instantly via `npx` with the command `npx github:zenapta/opensource-health-scorecard --repo <owner/name>` (for example, `npx github:zenapta/opensource-health-scorecard --repo facebook/react` will analyze the React library and return output like "✅ Score: 98/100" with details on last commit time, issue resolution speed, and health status). The tool stands out for three reasons: it uses multi-aspect scoring that goes beyond simple star counts to analyze real maintenance metrics, it's privacy-first with all analysis happening locally—no telemetry, no unnecessary API keys, and no data tracking—and it's designed for developer experience with integration into CI/CD pipelines and quick sanity checks before adding new dependencies to package.json. The project is actively improving the scoring algorithm, and contributions are welcome; if you have ideas for better metrics or want to add support for more platforms, feel free to open a Pull Request and check out the CONTRIBUTING.md for guidelines.
